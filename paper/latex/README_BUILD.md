# Build instructions (latex_improved)

This LaTeX project is evidence-locked to the contents of the provided bundle.
It uses `biblatex` + `biber` (BibTeX is not available in the build environment).

## Compile (recommended)
From this directory:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

If you want to clean aux files:

```bash
latexmk -C
```

Figures are provided as PDF files under `figures/` and are not regenerated by this bundle.
